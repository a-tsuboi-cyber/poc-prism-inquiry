# poc-prism-inquiry

PRISM一次受けAIアシスタント (PoC)

## 📌 概要
PRISMシステムを利用する社内外のユーザーからの問い合わせを生成AIで一次受けし、自己解決率向上と運用・開発チームの負荷軽減を図るWebアプリケーションです。
自己解決しなかった問い合わせは、自動要約・カテゴリ分類・緊急度判定を行ってチケットエスカレーションします。
