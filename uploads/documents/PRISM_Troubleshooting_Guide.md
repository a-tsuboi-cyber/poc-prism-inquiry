# PRISM システム障害・エラーコード対応手順書

## 1. 504 Gateway Timeout が発生した場合
- **原因**: 2GBを超える大容量ファイルのアップロード、またはCloudFrontとオリジンサーバー間の接続タイムアウト。
- **対処法**:
  1. ファイルサイズを2GB未満にエンコード（推奨ビットレート: 8Mbps以下）。
  2. AWS S3へのマルチパートアップロード機能が有効になっているか設定確認。
  3. 解消しない場合は運用チームへ即時エスカレーション。

## 2. 画像サムネイルが反映されない場合
- **原因**: CloudFrontのエッジキャッシュ（TTL: 15分）。
- **対処法**:
  1. ブラウザでキャッシュクリア（Ctrl+F5 / Cmd+Shift+R）。
  2. 緊急時は管理画面の「キャッシュパージ」より対象アセットIDを指定してキャッシュ無効化リクエストを実行。
